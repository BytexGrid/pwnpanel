# pwnpanel Project Document

## Project Overview

pwnpanel is a desktop application built with Electron and React that serves as a graphical launcher and installer for popular pentesting tools. It aims to provide a centralized and user-friendly interface to manage and run security tools.

## Core Features (Planned & In-Progress)

1.  **Tool Management:**
    *   Browse tools by category (Web, Spoofing, etc.).
    *   Filter tools by name using a search bar.
    *   **Advanced Installation:** Execute complex, multi-step installation scripts (e.g., installing dependencies, compiling from source) and stream the live output to a dedicated terminal tab.
    *   Check the installation status of each tool.
    *   **Integrated Run Options:** Run installed tools either by launching their native GUI or by executing them within the app's terminal manager.

2.  **Multi-Tab Terminal:**
    *   A persistent terminal view capable of managing multiple tabs.
    *   Each tab will run a separate process (installations, scripts).
    *   Provide real-time `stdout` and `stderr` from the running process.
    *   Allow for basic process control (e.g., stopping a command).

3.  **Script Runner:**
    *   A separate panel to execute standalone scripts from installed tools.
    *   Allow users to select from multiple available scripts within a tool's folder.
    *   Run scripts in a new tab in the Multi-Tab Terminal.
    *   View script output, README, and License information in a tabbed interface.

4.  **Backend:**
    *   Uses Node.js `child_process` to execute installation and run commands.
    *   Securely communicates between the frontend (React) and the main process (Electron) using IPC channels.

## Progress Log

### v0.0 (Proof of Concept by @hejhdiss)
- **Status:** Completed (External)
- **Details:**
    - A proof-of-concept (PoC) named **PWNTOOL** was developed in Python/Tkinter by @hejhdiss to serve as a blueprint for `pwnpanel`.
    - The source code is available in `sample.py`.
    - This PoC demonstrates core backend logic for tool management, focusing on Ettercap.
    - **Key Features Demonstrated:**
        - A GUI for installing tools with complex, multi-option installation scripts (from source, with/without dependencies, via package manager).
        - An integrated terminal manager that can run commands as `sudo` by piping a password.
        - Real-time command output streaming to the UI.
        - Logic for checking a tool's installation status (`which ettercap`).
        - A dedicated run interface for launching a tool in either GUI or text-based mode.
- **Relation to pwnpanel:** This PoC validates the core concepts and provides a working model for the installation and process execution logic that needs to be implemented in Node.js for `pwnpanel`.

### v0.1 (Initial Scaffold)
-   **Status:** Completed
-   **Details:**
    -   Set up an Electron project with React and TypeScript using Vite.
    -   Created the basic component structure: `Layout`, `Sidebar`, `Content`, `ToolCard`, `ScriptRunner`.
    -   Implemented a two-panel layout to switch between "Tool Installer" and "Script Runner" views.
    -   Set up basic IPC communication to run commands from the frontend in the main process.
-   **Issues:**
    -   UI is very basic and uses inline styles.
    -   Installation process is failing (Git error 128).
    -   Many UI elements are not yet functional (Categories, Search, Run button).
    -   Script runner is not fully implemented or tested.

### v0.2 (Bug Fixes & UI Refactor)
-   **Status:** Completed

    -   Fixed text overflow issues in tool cards.
    -   Removed visual glitches (stray dot in sidebar).
    -   Centralized application state (tools list) to ensure the UI is reactive.
    -   Implemented correct UI updates after a tool is successfully installed (Install button changes to Run).

    -   Improved error reporting for installation failures.

### v0.5 (Terminal & Advanced Installation)
- **Status:** Completed
- **Details:**
    - Implemented the core advice from @hejhdiss by building a multi-tab terminal manager.
    - Refactored the entire application to use a centralized state management approach for the terminal, making it more robust.
    - The backend in `main.ts` can now manage multiple concurrent child processes, each linked to a terminal tab.
    - Tool installations are now run in a terminal tab, showing live output to the user.
    - Updated the Ettercap installation command to the advanced multi-step version.
- **Issues:**
    - **Sudo Required:** The current implementation cannot handle commands that require `sudo` because there is no mechanism to provide a password. The Ettercap installation will fail.
- **Next Steps:**
    - Implement a secure way to handle `sudo` passwords, likely by prompting the user and piping the password to `sudo -S`, similar to the Python PoC.
    - Fully implement the "Script Runner" view to use the new terminal manager.
